# SkillMesh MVP v1 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 打通一条端到端闭环——从 Git 仓库安装 Skill 到 Claude Code / Codex 目录，并能把 Skill 制品发布到 SkillMesh 注册中心供搜索与下载。

**Architecture:** 中心化管理、客户端拉取、本地执行。本机跑 Keycloak（OIDC issuer）+ MinIO（S3 制品存储）+ Spring Boot API（直连远程 PostgreSQL 18.4）；Go CLI 走 OIDC 授权码 + PKCE 拿 token，exec 系统 git 做来源解析，通过适配器原子安装到 Agent 原生目录；Vue 前端只读展示。

**Tech Stack:** Java 21 · Spring Boot 3.5.3 · Spring Data JPA · Spring Security OAuth2 Resource Server · Flyway · PostgreSQL 18.4 · MinIO Java SDK 8.5.17 · Keycloak 26.8.1 · Go 1.24 + cobra · Vue 3 + Vite + TypeScript + vitest

## Global Constraints

以下约束适用于每个任务，不再逐条重复：

- **API 基址**：`http://localhost:8080/api/v1`，所有路由挂在此前缀下（详细设计 §2.1）。
- **JSON 字段**：`snake_case`。**错误格式**：problem+json，字段 `type` / `title` / `status` / `code` / `detail` / `request_id` / `retryable` / `field_errors`；客户端只按 `code` 分支。
- **契约**：`api-spec/openapi.yaml` 是手写契约，从 [doc/详细设计.md](../../doc/详细设计.md) §2.3 的 YAML 代码块**逐字**抽出，不从代码生成（附录 A.1）。任何接口变更先改 YAML。
- **DDL**：`db/migrations/V1__init.sql` 从 §1.2 的 SQL 代码块**逐字**抽出，含 `BEGIN;` / `COMMIT;`。
- **数据库**：`jdbc:postgresql://123.56.146.58:5432/skill_mesh`，用户 `gis_project`（superuser）。凭据只进 `.env`，已 gitignore。
- **测试库**：同一实例的独立 schema `skillmesh_test`，Flyway 自动建表，不碰 `public`。
- **制品存储**：bucket `skillmesh-artifacts`（测试用 `skillmesh-test-artifacts`）。临时 key `tmp/{skill_id}/{version_id}/{uuid}.tar.gz`，正式 key `{skill_id}/{version}/{sha256}.tar.gz`；正式 key 不可覆盖。
- **版本不可变**：`skill_versions` 的 `UNIQUE (skill_id, version)` 在第一次建表即存在；同版本号二次创建返回 409 `VERSION_CONFLICT`。
- **一个文件一个类**：Java 每文件一个类，DTO 用 record；Go 一个文件一个职责。
- **端口**（已按本机实际占用情况核对，9000/9001 被 SonarQube 占、5173 被占）：API `127.0.0.1:8080`、MinIO `127.0.0.1:9100`（控制台 `127.0.0.1:9101`）、Keycloak `127.0.0.1:8180`（relative path `/kc`）、Vite dev `127.0.0.1:5174`、CLI OAuth 回调 `127.0.0.1:53682`。**所有本地服务只绑回环地址，不监听 `0.0.0.0`。**
- **不推送**：本地 `git add` / `commit` 直接做，`git push` 必须用户明确授权。

- [ ] **Step 2: 写 build-minio.sh**

MinIO 官方二进制已于 2025-10 下架（`dl.min.io` 返回 410 Gone），本机 `github.com` 也不可达，只能用已有 Go 工具链从源码构建。注意 `go install` 不允许交叉编译 + GOBIN，必须用 `go build -o`。

```bash
#!/usr/bin/env bash
# 从源码构建 MinIO 服务端。官方 CE 二进制已下架，见 README 风险表。
set -euo pipefail
ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/../.." && pwd)"
BIN="$ROOT/infra/bin"
WORK="${TMPDIR:-/tmp}/skillmesh-minio-build"
VERSION="v0.0.0-20260212201848-7aac2a2c5b7c"

# 选择 Go 工具链。32 位工具链的 linker 链 amd64 大二进制会 OOM，
# 因此用 SKILLMESH_GO_BIN 指向一个 windows-amd64 版 Go。
GO_BIN="${SKILLMESH_GO_BIN:-go}"
GO_BIN_PATH="$(command -v "$GO_BIN" || echo "$GO_BIN")"
# 系统里可能预置了指向别的工具链的 GOROOT，不显式对齐会报 "no such tool compile"
export GOROOT="$(cd "$(dirname "$GO_BIN_PATH")/.." && pwd)"

mkdir -p "$BIN" "$WORK"
if [ -f "$BIN/minio.exe" ]; then
  echo "minio.exe 已存在，跳过构建"
  exit 0
fi

cd "$WORK"
[ -f go.mod ] || "$GO_BIN" mod init skillmesh/minio-build
GOFLAGS=-mod=mod "$GO_BIN" get "github.com/minio/minio@$VERSION"
GOARCH=amd64 "$GO_BIN" build -o "$BIN/minio.exe" github.com/minio/minio
"$BIN/minio.exe" --version
```

> 本机用法：`SKILLMESH_GO_BIN=D:/tmp/goamd64/go/bin/go.exe bash infra/scripts/build-minio.sh`。
> 工具链来源：`https://dl.google.com/go/go1.24.9.windows-amd64.zip`（官方源，可达）。

- [ ] **Step 3: 写 fetch-keycloak.sh**

Keycloak 发行包在 Maven Central 上（本机 Maven Central 可达，GitHub 不可达）。

```bash
#!/usr/bin/env bash
set -euo pipefail
ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/../.." && pwd)"
BIN="$ROOT/infra/bin"
VERSION="26.8.1"
URL="https://repo1.maven.org/maven2/org/keycloak/keycloak-quarkus-dist/${VERSION}/keycloak-quarkus-dist-${VERSION}.zip"
ZIP="$BIN/keycloak-${VERSION}.zip"

mkdir -p "$BIN"
if [ -d "$BIN/keycloak-${VERSION}" ]; then
  echo "Keycloak ${VERSION} 已存在，跳过下载"
  exit 0
fi
[ -f "$ZIP" ] || curl -fSL --retry 3 -o "$ZIP" "$URL"
unzip -q -o "$ZIP" -d "$BIN"
rm -f "$ZIP"
test -x "$BIN/keycloak-${VERSION}/bin/kc.bat" || test -f "$BIN/keycloak-${VERSION}/bin/kc.bat"
echo "Keycloak ${VERSION} 就绪"
```

`start-minio.sh`：

```bash
#!/usr/bin/env bash
set -euo pipefail
ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/../.." && pwd)"
BIN="$ROOT/infra/bin"
LOGS="$BIN/logs"
DATA="${SKILLMESH_DATA_DIR:-$HOME/.skillmesh-data}/minio"
set -a; [ -f "$ROOT/.env" ] && . "$ROOT/.env"; set +a

mkdir -p "$LOGS" "$DATA"
[ -f "$BIN/minio.exe" ] || bash "$ROOT/infra/scripts/build-minio.sh"
if curl -sf -o /dev/null "http://127.0.0.1:9000/minio/health/live"; then
  echo "MinIO 已在运行"; exit 0
fi
MINIO_ROOT_USER="${SM_MINIO_ACCESS_KEY:-skillmesh}" \
MINIO_ROOT_PASSWORD="${SM_MINIO_SECRET_KEY:-skillmesh-dev-secret}" \
nohup "$BIN/minio.exe" server "$DATA" \
  --address "127.0.0.1:9100" --console-address "127.0.0.1:9101" \
  > "$LOGS/minio.log" 2>&1 &
echo $! > "$LOGS/minio.pid"
for _ in $(seq 1 30); do
  curl -sf -o /dev/null "http://127.0.0.1:9100/minio/health/live" && { echo "MinIO 就绪 127.0.0.1:9100"; exit 0; }
  sleep 1
done
echo "MinIO 启动超时，见 $LOGS/minio.log" >&2; exit 1
```

`start-keycloak.sh`：

```bash
#!/usr/bin/env bash
set -euo pipefail
ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/../.." && pwd)"
BIN="$ROOT/infra/bin"
LOGS="$BIN/logs"
VERSION="26.8.1"
KC="$BIN/keycloak-${VERSION}"
set -a; [ -f "$ROOT/.env" ] && . "$ROOT/.env"; set +a

mkdir -p "$LOGS"
[ -d "$KC" ] || bash "$ROOT/infra/scripts/fetch-keycloak.sh"
mkdir -p "$KC/data/import"
cp "$ROOT/infra/keycloak/realm-skillmesh.json" "$KC/data/import/"
if curl -sf -o /dev/null "http://127.0.0.1:8180/kc/realms/skillmesh/.well-known/openid-configuration"; then
  echo "Keycloak 已在运行"; exit 0
fi
export KC_BOOTSTRAP_ADMIN_USERNAME="${SM_KEYCLOAK_ADMIN_USER:-admin}"
export KC_BOOTSTRAP_ADMIN_PASSWORD="${SM_KEYCLOAK_ADMIN_PASSWORD:-admin}"
nohup "$KC/bin/kc.bat" start-dev --http-port=8180 --http-relative-path=/kc --import-realm \
  > "$LOGS/keycloak.log" 2>&1 &
echo $! > "$LOGS/keycloak.pid"
for _ in $(seq 1 120); do
  curl -sf -o /dev/null "http://127.0.0.1:8180/kc/realms/skillmesh/.well-known/openid-configuration" \
    && { echo "Keycloak 就绪 :8180/kc"; exit 0; }
  sleep 2
done
echo "Keycloak 启动超时，见 $LOGS/keycloak.log" >&2; exit 1
```

```bash
        }
```

```java
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.http.HttpStatus;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.MethodArgumentNotValidException;
import org.springframework.web.bind.annotation.ExceptionHandler;
import org.springframework.web.bind.annotation.RestControllerAdvice;

@RestControllerAdvice
public class GlobalExceptionHandler {

    private static final Logger log = LoggerFactory.getLogger(GlobalExceptionHandler.class);
    private static final String BASE = "https://skills.example.com/problems/";

    @ExceptionHandler(ApiException.class)
    ResponseEntity<Problem> handleApi(ApiException ex, HttpServletRequest req) {
        return ResponseEntity.status(ex.status()).body(Problem.of(
            BASE + ex.code().toLowerCase().replace('_', '-'), ex.code(), ex.status(),
            ex.code(), ex.getMessage(), requestId(req), false));
    }

    @ExceptionHandler(MethodArgumentNotValidException.class)
    ResponseEntity<Problem> handleValidation(MethodArgumentNotValidException ex, HttpServletRequest req) {
        List<Problem.FieldError> fields = ex.getBindingResult().getFieldErrors().stream()
            .map(fe -> new Problem.FieldError(fe.getField(), "INVALID", fe.getDefaultMessage()))
            .toList();
        Problem body = new Problem(BASE + "validation-failed", ErrorCodes.VALIDATION_FAILED,
            400, ErrorCodes.VALIDATION_FAILED, "请求字段校验失败", requestId(req), false, fields);
        return ResponseEntity.badRequest().body(body);
    }

    @ExceptionHandler(Exception.class)
    ResponseEntity<Problem> handleOther(Exception ex, HttpServletRequest req) {
        log.error("未处理异常 request_id={}", requestId(req), ex);
        Problem body = Problem.of(BASE + "internal", "Internal Server Error", 500,
            ErrorCodes.INTERNAL, "服务内部错误", requestId(req), true);
        return ResponseEntity.status(HttpStatus.INTERNAL_SERVER_ERROR).body(body);
    }

    private static String requestId(HttpServletRequest req) {
        String id = req.getHeader("X-Request-Id");
        return id != null && !id.isBlank() ? id : "req_" + UUID.randomUUID().toString().replace("-", "");
    }
}
```

`CurrentUserService.java`：

```java
package com.skillmesh.api.auth;

import java.time.OffsetDateTime;
import java.time.ZoneOffset;
import java.util.UUID;
import org.springframework.security.oauth2.jwt.Jwt;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

@Service
public class CurrentUserService {

    private final UserRepository users;

    public CurrentUserService(UserRepository users) {
        this.users = users;
    }

    @Transactional
    public CurrentUser current(Jwt jwt) {
        String issuer = jwt.getIssuer().toString();
        String subject = jwt.getSubject();
        UserEntity user = users.findByOidcIssuerAndOidcSubject(issuer, subject)
            .orElseGet(() -> provision(issuer, subject, jwt));
        OffsetDateTime now = OffsetDateTime.now(ZoneOffset.UTC);
        user.setLastLoginAt(now);
        user.setUpdatedAt(now);
        users.save(user);
        return new CurrentUser(user.getId(), subject, user.getDisplayName(), user.getEmail());
    }

    private UserEntity provision(String issuer, String subject, Jwt jwt) {
        OffsetDateTime now = OffsetDateTime.now(ZoneOffset.UTC);
        UserEntity user = new UserEntity();
        user.setId(UUID.randomUUID());
        user.setOidcIssuer(issuer);
        user.setOidcSubject(subject);
        user.setDisplayName(displayName(jwt));
        user.setEmail(jwt.getClaimAsString("email"));
        user.setStatus("active");
        user.setCreatedAt(now);
        user.setUpdatedAt(now);
        return users.save(user);
    }

    private static String displayName(Jwt jwt) {
        for (String claim : List.of("name", "preferred_username")) {
            String value = jwt.getClaimAsString(claim);
            if (value != null && !value.isBlank()) {
                return value;
            }
        }
        return jwt.getSubject();
    }
}
```

```java
package com.skillmesh.api.skill;

import com.skillmesh.api.auth.CurrentUser;
import com.skillmesh.api.common.ApiException;
import com.skillmesh.api.common.ErrorCodes;
import com.skillmesh.api.skill.dto.CreateSkillRequest;
import com.skillmesh.api.skill.dto.SkillPage;
import com.skillmesh.api.skill.dto.SkillResponse;
import java.nio.charset.StandardCharsets;
import java.time.OffsetDateTime;
import java.time.ZoneOffset;
import java.util.ArrayList;
import java.util.Base64;
import java.util.List;
import java.util.Map;
import java.util.UUID;
import org.springframework.data.domain.PageRequest;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

@Service
public class SkillService {

    private static final int MAX_LIMIT = 100;

    private final SkillRepository skills;

    public SkillService(SkillRepository skills) {
        this.skills = skills;
    }

    @Transactional
    public SkillResponse create(CurrentUser user, CreateSkillRequest req) {
        if (skills.existsByOwnerUserIdAndOrganizationIdIsNullAndSlug(user.id(), req.slug())) {
            throw new ApiException(409, ErrorCodes.SLUG_TAKEN, "slug 已被占用: " + req.slug());
        }
        OffsetDateTime now = OffsetDateTime.now(ZoneOffset.UTC);
        SkillEntity e = new SkillEntity();
        e.setId(UUID.randomUUID());
        e.setSlug(req.slug());
        e.setName(req.name());
        e.setDescription(req.description());
        e.setOwnerUserId(user.id());
        e.setOrganizationId(req.organization_id());
        e.setOwnerTeamId(req.owner_team_id());
        e.setVisibility(req.visibility());
        e.setStatus("active");
        e.setTags(req.tags() == null ? new String[0] : req.tags().toArray(new String[0]));
        e.setMetadataJson(req.metadata() == null ? Map.of() : req.metadata());
        e.setCreatedAt(now);
        e.setUpdatedAt(now);
        return toResponse(skills.save(e));
    }

    @Transactional(readOnly = true)
    public SkillResponse get(CurrentUser user, UUID id) {
        SkillEntity e = skills.findById(id).orElseThrow(() -> ApiException.notFound("Skill"));
        if (!canView(user, e)) {
            throw ApiException.notFound("Skill");
        }
        return toResponse(e);
    }

    @Transactional(readOnly = true)
    public SkillPage search(CurrentUser user, String q, String visibility, String tag,
                            Integer limit, String cursor) {
        int size = limit == null ? 20 : Math.clamp(limit, 1, MAX_LIMIT);
        OffsetDateTime cursorTime = null;
        UUID cursorId = null;
        if (cursor != null && !cursor.isBlank()) {
            String[] parts = new String(decode(cursor), StandardCharsets.UTF_8).split("\\|", 2);
            cursorTime = OffsetDateTime.parse(parts[0]);
            cursorId = UUID.fromString(parts[1]);
        }
        List<SkillEntity> rows =
            skills.search(user.id(), normalize(q), visibility, tag, cursorTime, cursorId,
                PageRequest.of(0, size + 1));
        boolean hasMore = rows.size() > size;
        List<SkillEntity> page = hasMore ? rows.subList(0, size) : rows;
        List<SkillResponse> items = new ArrayList<>(page.size());
        for (SkillEntity e : page) {
            items.add(toResponse(e));
        }
        String next = null;
        if (hasMore && !page.isEmpty()) {
            SkillEntity last = page.get(page.size() - 1);
            next = encode(last.getUpdatedAt().toString() + "|" + last.getId());
        }
        return new SkillPage(items, next, hasMore);
    }

    static boolean canView(CurrentUser user, SkillEntity e) {
        return "public".equals(e.getVisibility()) || user.id().equals(e.getOwnerUserId());
    }

    private static String normalize(String q) {
        return q == null || q.isBlank() ? null : "%" + q.toLowerCase() + "%";
    }

    static SkillResponse toResponse(SkillEntity e) {
        return new SkillResponse(e.getId(), e.getSlug(), e.getName(), e.getDescription(),
            e.getVisibility(), e.getStatus(), e.getOwnerUserId(), e.getOrganizationId(),
            e.getOwnerTeamId(), List.of(e.getTags() == null ? new String[0] : e.getTags()),
            e.getMetadataJson(), e.getLatestVersion(), e.getCreatedAt(), e.getUpdatedAt());
    }

    private static byte[] decode(String cursor) {
        return Base64.getUrlDecoder().decode(cursor);
    }

    private static String encode(String raw) {
        return Base64.getUrlEncoder().withoutPadding()
            .encodeToString(raw.getBytes(StandardCharsets.UTF_8));
    }
}
```

```java
package com.skillmesh.api.skill;

import com.skillmesh.api.auth.CurrentUser;
import com.skillmesh.api.auth.CurrentUserService;
import com.skillmesh.api.skill.dto.CreateSkillRequest;
import com.skillmesh.api.skill.dto.SkillPage;

import java.net.URI;
import java.util.UUID;
import org.springframework.http.ResponseEntity;
import org.springframework.security.core.annotation.AuthenticationPrincipal;
import org.springframework.security.oauth2.jwt.Jwt;
import org.springframework.web.bind.annotation.*;

@RestController
@RequestMapping("/api/v1/skills")
public class SkillController {

    private final SkillService skills;
    private final CurrentUserService currentUserService;

    public SkillController(SkillService skills, CurrentUserService currentUserService) {
        this.skills = skills;
        this.currentUserService = currentUserService;
    }

    @PostMapping
    public ResponseEntity<SkillResponse> create(@AuthenticationPrincipal Jwt jwt,
                                                @Valid @RequestBody CreateSkillRequest req) {

        return ResponseEntity.created(URI.create("/api/v1/skills/" + created.id())).body(created);

                          @RequestParam(required = false) String tag,
                          @RequestParam(required = false) Integer limit,
                          @RequestParam(required = false) String cursor) {
        return skills.search(currentUserService.current(jwt), q, visibility, tag, limit, cursor);
    }

    @GetMapping("/{skillId}")
    public SkillResponse get(@AuthenticationPrincipal Jwt jwt,
                             @PathVariable UUID skillId) {
        return skills.get(currentUserService.current(jwt), skillId);
    }
}
```

```java
                    .content(versionBody("1.0.0", zipOf("SKILL.md", "# X\n"))))
                .andExpect(i == 0 ? status().isCreated() : status().isConflict())
                .andReturn();
            if (i == 1) {
                org.junit.jupiter.api.Assertions.assertEquals("VERSION_CONFLICT",
                    json.readTree(result.getResponse().getContentAsString()).path("code").asText());

    private String createSkill(String slug) throws Exception {
        String resp = mockMvc.perform(post("/api/v1/skills").header("Authorization", auth)
                .contentType(MediaType.APPLICATION_JSON)
                .content(json.writeValueAsString(Map.of("slug", slug, "name", slug,
                    "description", "", "visibility", "private"))))
            .andExpect(status().isCreated())
            .andReturn().getResponse().getContentAsString();
        return json.readTree(resp).path("id").asText();
    }

    private String versionBody(String version, byte[] zip) throws Exception {
        return versionBodyWithDigest(version, zip, sha256(zip));
    }

    private String versionBodyWithDigest(String version, byte[] zip, String digest) throws Exception {
        return json.writeValueAsString(Map.of(
            "version", version, "channel", "stable", "size_bytes", zip.length,
            "sha256", digest, "file_count", 1,
            "manifest", java.util.List.of(Map.of(
                "path", "SKILL.md", "sha256", digest, "size_bytes", zip.length))));
    }

    static byte[] zipOf(String name, String content) throws Exception {
        ByteArrayOutputStream out = new ByteArrayOutputStream();
        try (ZipOutputStream zos = new ZipOutputStream(out, StandardCharsets.UTF_8)) {
            zos.putNextEntry(new ZipEntry(name));
            zos.write(content.getBytes(StandardCharsets.UTF_8));
            zos.closeEntry();
        }
        return out.toByteArray();
    }

    static String sha256(byte[] data) throws Exception {
        return HexFormat.of().formatHex(MessageDigest.getInstance("SHA-256").digest(data));
    }
}
```

```java
package com.skillmesh.api.artifact;

import io.minio.*;
import io.minio.http.Method;
import java.io.InputStream;
import java.time.Duration;
import java.util.Map;
import java.util.concurrent.TimeUnit;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.stereotype.Component;

@Component
public class ArtifactStorage {

    private final MinioClient client;
    private final String bucket;

    public ArtifactStorage(MinioClient client,
                           @Value("${skillmesh.minio.bucket}") String bucket) {
        this.client = client;
        this.bucket = bucket;
    }

    public void ensureBucket() {
        try {
            if (!client.bucketExists(BucketExistsArgs.builder().bucket(bucket).build())) {
                client.makeBucket(MakeBucketArgs.builder().bucket(bucket).build());
            }
        } catch (Exception e) {
            throw new IllegalStateException("对象存储 bucket 不可用: " + bucket, e);
        }
    }

    public String presignedPut(String key, Duration ttl) {
        try {
            return client.getPresignedObjectUrl(GetPresignedObjectUrlArgs.builder()
                .method(Method.PUT).bucket(bucket).object(key).expiry((int) ttl.toSeconds())
                .build());
        } catch (Exception e) {
            throw new IllegalStateException("生成上传地址失败: " + key, e);
        }
    }

    public String presignedGet(String key, Duration ttl) {
        try {
            return client.getPresignedObjectUrl(GetPresignedObjectUrlArgs.builder()
                .method(Method.GET).bucket(bucket).object(key).expiry((int) ttl.toSeconds())
                .build());
        } catch (Exception e) {
            throw new IllegalStateException("生成下载地址失败: " + key, e);
        }
    }

    public void put(String key, byte[] data, String contentType) {
        try (ByteArrayInputStreamHolder holder = new ByteArrayInputStreamHolder(data)) {
            client.putObject(PutObjectArgs.builder()
                .bucket(bucket).object(key)
                .stream(holder.stream, data.length, -1)
                .contentType(contentType)
                .build());
        } catch (Exception e) {
            throw new IllegalStateException("写入对象失败: " + key, e);
        }
    }

    public InputStream get(String key) {
        try {
            return client.getObject(GetObjectArgs.builder().bucket(bucket).object(key).build());
        } catch (Exception e) {
            throw new IllegalStateException("读取对象失败: " + key, e);
        }
    }

    public boolean exists(String key) {
        try {
            client.statObject(StatObjectArgs.builder().bucket(bucket).object(key).build());
            return true;
        } catch (Exception e) {
            return false;
        }
    }

    public void delete(String key) {
        try {
            client.removeObject(RemoveObjectArgs.builder().bucket(bucket).object(key).build());
        } catch (Exception ignored) {
            // 临时对象清理失败不阻断主流程
        }
    }

    /** 让 try-with-resources 能关掉内存流，同时不引入额外类型 */
    private record ByteArrayInputStreamHolder(java.io.ByteArrayInputStream stream)
            implements AutoCloseable {
        @Override public void close() throws java.io.IOException { stream.close(); }
    }
}
```

```java
package com.skillmesh.api.artifact;

import com.skillmesh.api.auth.CurrentUser;
import com.skillmesh.api.common.ApiException;
import com.skillmesh.api.common.ErrorCodes;
import com.skillmesh.api.version.SkillVersionRepository;
import java.io.ByteArrayInputStream;
import java.io.InputStream;
import java.security.MessageDigest;
import java.time.Duration;
import java.time.OffsetDateTime;
import java.time.ZoneOffset;
import java.util.HexFormat;
import java.util.List;
import java.util.Map;
import java.util.UUID;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

@Service
public class ArtifactService {

    public static final Duration DOWNLOAD_TTL = Duration.ofMinutes(5);
    public static final Duration UPLOAD_TTL = Duration.ofMinutes(30);
    public static final long MAX_ARTIFACT_BYTES = 52_428_800L;

    private final ArtifactStorage storage;
    private final ArtifactRepository artifacts;
    private final SkillVersionRepository versions;

    public ArtifactService(ArtifactStorage storage, ArtifactRepository artifacts,
                           SkillVersionRepository versions) {
        this.storage = storage;
        this.artifacts = artifacts;
        this.versions = versions;
        storage.ensureBucket();
    }

    public String tempKey(UUID skillId, UUID versionId) {
        return "tmp/%s/%s/%s.tar.gz".formatted(skillId, versionId, UUID.randomUUID());
    }

    public String finalKey(UUID skillId, String version, String sha256) {
        return "%s/%s/%s.tar.gz".formatted(skillId, version, sha256);
    }

    @Transactional
    public ArtifactEntity promote(CurrentUser user, UUID versionId, String tempKey,
                                  String expectedSha256, long expectedSize) {
        if (!storage.exists(tempKey)) {
            throw new ApiException(422, ErrorCodes.ARTIFACT_MISSING, "上传对象不存在，请重新上传");
        }
        byte[] bytes = readAll(storage.get(tempKey));
        if (bytes.length > MAX_ARTIFACT_BYTES) {
            throw new ApiException(422, ErrorCodes.VALIDATION_FAILED, "制品超过大小上限");
        }
        String actual = sha256(bytes);
        if (!actual.equals(expectedSha256)) {
            storage.delete(tempKey);
            throw new ApiException(422, ErrorCodes.DIGEST_MISMATCH,
                "制品摘要不匹配：声明 " + expectedSha256 + "，实际 " + actual);
        }
        String storageKey = finalKey(findSkillId(versionId), findVersion(versionId), actual);
        storage.put(storageKey, bytes, "application/zip");

        ArtifactEntity artifact = artifacts.findBySha256(actual).orElseGet(() -> {
            ArtifactEntity a = new ArtifactEntity();
            a.setId(UUID.randomUUID());
            a.setSha256(actual);
            a.setStorageKey(storageKey);
            a.setContentType("application/zip");
            a.setSizeBytes(bytes.length);
            a.setFileCount(1);
            a.setManifestJson(List.of());
            a.setCreatedAt(OffsetDateTime.now(ZoneOffset.UTC));
            return a;
        });
        artifacts.save(artifact);
        storage.delete(tempKey);
        return artifact;
    }

    @Transactional(readOnly = true)
    public ArtifactEntity require(UUID artifactId) {
        return artifacts.findById(artifactId)
            .orElseThrow(() -> ApiException.notFound("Artifact"));
    }

    public String presignedDownload(ArtifactEntity artifact) {
        return storage.presignedGet(artifact.getStorageKey(), DOWNLOAD_TTL);
    }

    public InputStream open(ArtifactEntity artifact) {
        return storage.get(artifact.getStorageKey());
    }

    public static String sha256(byte[] data) {
        try {
            return HexFormat.of().formatHex(MessageDigest.getInstance("SHA-256").digest(data));
        } catch (java.security.NoSuchAlgorithmException e) {
            throw new IllegalStateException("SHA-256 不可用", e);
        }
    }

    private byte[] readAll(InputStream in) {
        try (in) {
            return in.readAllBytes();
        } catch (java.io.IOException e) {
            throw new IllegalStateException("读取上传对象失败", e);
        }
    }

    private UUID findSkillId(UUID versionId) {
        return versions.findById(versionId).map(v -> v.getSkillId())
            .orElseThrow(() -> ApiException.notFound("版本"));
    }

    private String findVersion(UUID versionId) {
        return versions.findById(versionId).map(v -> v.getVersion())
            .orElseThrow(() -> ApiException.notFound("版本"));
    }
}
```

```java
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

@Service
public class SkillVersionService {

    private final SkillVersionRepository versions;
    private final SkillRepository skills;
    private final ArtifactService artifacts;

    public SkillVersionService(SkillVersionRepository versions, SkillRepository skills,
                               ArtifactService artifacts) {
        this.versions = versions;
        this.skills = skills;
        this.artifacts = artifacts;
    }

    @Transactional
    public CreateVersionResponse create(CurrentUser user, UUID skillId,
                                        CreateVersionRequest req) {
        SkillEntity skill = skills.findById(skillId).orElseThrow(() -> ApiException.notFound("Skill"));
        if (!SkillService.canView(user, skill)) {
            throw ApiException.notFound("Skill");
        }
        if (versions.existsBySkillIdAndVersion(skillId, req.version())) {
            throw ApiException.versionConflict("版本已存在且不可覆盖: " + req.version());
        }
        OffsetDateTime now = OffsetDateTime.now(ZoneOffset.UTC);
        SkillVersionEntity v = new SkillVersionEntity();
        v.setId(UUID.randomUUID());
        v.setSkillId(skillId);
        v.setSourceId(req.source_id());
        v.setVersion(req.version());
        v.setChannel(req.channel());
        v.setSourceCommit(req.source_commit());
        v.setChangelog(req.changelog() == null ? "" : req.changelog());
        v.setManifestJson(Map.of());
        v.setStatus("draft");
        v.setCreatedBy(user.id());
        v.setCreatedAt(now);
        versions.save(v);

        String tempKey = artifacts.tempKey(skillId, v.getId());
        UploadSession upload = new UploadSession(
            v.getId(), "skill_artifact", "created",
            new UploadSession.Upload("PUT", artifacts.presignedPut(tempKey, ArtifactService.UPLOAD_TTL),
                Map.of("Content-Type", "application/zip")),
            now.plus(ArtifactService.UPLOAD_TTL), null, null);
        return new CreateVersionResponse(v.getId(), v.getStatus(), upload, null);
    }

    /** 上传会话不独立建表：uploadId 即版本 id，临时 key 由请求带上，状态映射到 skill_versions.status */
    @Transactional
    public UploadSession complete(CurrentUser user, UUID uploadId, String tempKey,
                                  String declaredSha256) {
        SkillVersionEntity v = versions.findById(uploadId)
            .orElseThrow(() -> ApiException.notFound("上传会话"));
        if (!"draft".equals(v.getStatus())) {
            throw new ApiException(409, ErrorCodes.VERSION_CONFLICT, "上传会话已结束");
        }
        ArtifactEntity artifact = artifacts.promote(user, uploadId, tempKey,
            declaredSha256, 0L);
        OffsetDateTime now = OffsetDateTime.now(ZoneOffset.UTC);
        v.setArtifactId(artifact.getId());
        v.setStatus("published");
        v.setPublishedBy(user.id());
        v.setPublishedAt(now);
        versions.save(v);
        skills.findById(v.getSkillId()).ifPresent(s -> {
            s.setLatestVersion(v.getVersion());
            s.setUpdatedAt(now);
            skills.save(s);
        });
        return new UploadSession(uploadId, "skill_artifact", "completed", null,
            now.plusSeconds(60), artifact.getSha256(), null);
    }

    @Transactional(readOnly = true)
    public VersionPage list(CurrentUser user, UUID skillId) {
        SkillEntity skill = skills.findById(skillId).orElseThrow(() -> ApiException.notFound("Skill"));
        if (!SkillService.canView(user, skill)) {
            throw ApiException.notFound("Skill");
        }
        List<SkillVersionResponse> items = new ArrayList<>();
        for (SkillVersionEntity v : versions.findBySkillIdOrderByCreatedAtDesc(skillId)) {
            ArtifactSummary summary = null;
            if (v.getArtifactId() != null) {
                ArtifactEntity a = artifacts.require(v.getArtifactId());
                summary = new ArtifactSummary(a.getId(), a.getSha256(), a.getSizeBytes(),
                    a.getContentType());
            }
            items.add(new SkillVersionResponse(v.getId(), v.getSkillId(), v.getVersion(),
                v.getChannel(), v.getStatus(), v.getSourceCommit(), summary,
                v.getPublishedAt(), v.getCreatedAt()));
        }
        return new VersionPage(items, null, false);
    }
}
```

```java
import org.springframework.http.MediaType;

import org.springframework.security.core.annotation.AuthenticationPrincipal;
import org.springframework.security.oauth2.jwt.Jwt;
import org.springframework.web.bind.annotation.*;

@RestController
@RequestMapping("/api/v1/artifacts")
public class ArtifactController {

    private final ArtifactService artifacts;
    private final ArtifactRepository artifactRepository;
    private final SkillVersionRepository versions;
    private final SkillRepository skills;
    private final CurrentUserService currentUserService;

    public ArtifactController(ArtifactService artifacts, ArtifactRepository artifactRepository,
                              SkillVersionRepository versions, SkillRepository skills,
                              CurrentUserService currentUserService) {
        this.artifacts = artifacts;
        this.artifactRepository = artifactRepository;
        this.versions = versions;
        this.skills = skills;
        this.currentUserService = currentUserService;
    }

    @GetMapping("/{artifactId}/download")
    public ResponseEntity<?> download(@AuthenticationPrincipal Jwt jwt,
                                      @PathVariable UUID artifactId,
                                      @RequestParam(defaultValue = "redirect") String disposition) {
        CurrentUser user = currentUserService.current(jwt);
        ArtifactEntity artifact = artifacts.require(artifactId);
        requireVisible(user, artifact);
        if ("stream".equals(disposition)) {
            InputStream in = artifacts.open(artifact);
            return ResponseEntity.ok()
                .contentType(MediaType.parseMediaType(artifact.getContentType()))
                .header(HttpHeaders.CONTENT_DISPOSITION,
                    "attachment; filename=\"" + artifact.getStorageKey().substring(
                        artifact.getStorageKey().lastIndexOf('/') + 1) + "\"")
                .contentLength(artifact.getSizeBytes())
                .body(new InputStreamResource(in));
        }
        DownloadInfo info = new DownloadInfo(artifacts.presignedDownload(artifact),
            artifact.getSha256(), artifact.getSizeBytes(), artifact.getContentType(),
            OffsetDateTime.now(ZoneOffset.UTC).plus(ArtifactService.DOWNLOAD_TTL));
        return ResponseEntity.ok(info);
    }

    private void requireVisible(CurrentUser user, ArtifactEntity artifact) {
        for (SkillVersionEntity v : versions.findAll()) {
            if (artifact.getId().equals(v.getArtifactId())) {
                SkillEntity skill = skills.findById(v.getSkillId()).orElse(null);
                if (skill == null || !SkillService.canView(user, skill)) {
                    throw ApiException.notFound("Artifact");
                }
                return;
            }
        }
        throw ApiException.notFound("Artifact");
    }
}
```

```go
// Config 保存非敏感设置。凭据不进本文件，见 auth.Tokens。
type Config struct {
	Server    string         `yaml:"server"`
	ClientID  string         `yaml:"client_id"`
	Network   NetworkConfig  `yaml:"network"`
	Agents    map[string]Agent `yaml:"agents"`

	ConfigDir string `yaml:"-"`
	CacheDir  string `yaml:"-"`
}

type NetworkConfig struct {
	TimeoutSeconds int `yaml:"timeout_seconds"`
	MaxRetries     int `yaml:"max_retries"`
}

type Agent struct {
	Enabled       bool   `yaml:"enabled"`
	UserSkillsDir string `yaml:"user_skills_dir"`
	ProjectSkills string `yaml:"project_skills_dir"`
}

const (
	defaultServer   = "http://localhost:8080/api/v1"
	defaultClientID = "skillmesh-cli"
)

func defaults() Config {
	configDir, cacheDir := DefaultPaths()
	return Config{
		Server:    defaultServer,
		ClientID:  defaultClientID,
		Network:   NetworkConfig{TimeoutSeconds: 30, MaxRetries: 5},
		Agents: map[string]Agent{
			"claude-code": {Enabled: true, UserSkillsDir: homeDir() + "/.claude/skills", ProjectSkills: ".claude/skills"},
			"codex":       {Enabled: true, UserSkillsDir: codexHome() + "/skills", ProjectSkills: ".agents/skills"},
		},
		ConfigDir: configDir,
		CacheDir:  cacheDir,
	}
}

func Load() (Config, error) {
	cfg := defaults()
	if v := os.Getenv("SKILLMESH_SERVER"); v != "" {
		cfg.Server = v
	}
	if v := os.Getenv("SKILLMESH_CLIENT_ID"); v != "" {
		cfg.ClientID = v
	}

	data, err := os.ReadFile(filepath.Join(cfg.ConfigDir, "config.yaml"))
	if os.IsNotExist(err) {
		return cfg, nil
	}
	if err != nil {
		return cfg, fmt.Errorf("读取 config.yaml: %w", err)
	}
	var file Config
	if err := yaml.Unmarshal(data, &file); err != nil {
		return cfg, fmt.Errorf("解析 config.yaml: %w", err)
	}
	if file.Server != "" {
		cfg.Server = file.Server
	}
	if file.ClientID != "" {
		cfg.ClientID = file.ClientID
	}
	if file.Network.TimeoutSeconds > 0 {
		cfg.Network = file.Network
	}
	for name, agent := range file.Agents {
		cfg.Agents[name] = agent
	}
	return cfg, nil
}
```

```go
package auth

import (
	"encoding/json"
	"fmt"
	"os"
	"path/filepath"
	"time"
)

const credentialTarget = "skillmesh/tokens"

// Tokens 是登录态。优先存系统凭据管理器，失败时回退到权限 0600 的文件。
type Tokens struct {
	AccessToken  string    `json:"access_token"`
	RefreshToken string    `json:"refresh_token,omitempty"`
	ExpiresAt    time.Time `json:"expires_at"`
}

func (t Tokens) Valid() bool {
	return t.AccessToken != "" && time.Now().Add(time.Minute).Before(t.ExpiresAt)
}

func (t *Tokens) Save(path string) error {
	data, err := json.Marshal(t)
	if err != nil {
		return err
	}
	if err := putCredential(string(data)); err == nil {
		return nil
	}
	if err := os.MkdirAll(filepath.Dir(path), 0o700); err != nil {
		return err
	}
	return os.WriteFile(path, data, 0o600)
}

func LoadTokens(path string) (Tokens, error) {
	var t Tokens
	if raw, err := getCredential(); err == nil && raw != "" {
		if err := json.Unmarshal([]byte(raw), &t); err != nil {
			return t, fmt.Errorf("解析凭据: %w", err)
		}
		return t, nil
	}
	data, err := os.ReadFile(path)
	if err != nil {
		return t, err
	}
	if err := json.Unmarshal(data, &t); err != nil {
		return t, fmt.Errorf("解析 %s: %w", path, err)
	}
	return t, nil
}

func Clear(path string) error {
	deleteCredential()
	if err := os.Remove(path); err != nil && !os.IsNotExist(err) {
		return err
	}
	return nil
}
```

```go
package auth

import (
	"crypto/rand"
	"crypto/sha256"
	"encoding/base64"

type Verifier struct {
	Verifier  string
	Challenge string
}

// NewCodeVerifier 生成 RFC 7636 的 S256 码对。
func NewCodeVerifier() Verifier {
	raw := make([]byte, 32)
	mustRead(rand.Read(raw))
	verifier := base64.RawURLEncoding.EncodeToString(raw)
	sum := sha256.Sum256([]byte(verifier))
	return Verifier{Verifier: verifier, Challenge: base64.RawURLEncoding.EncodeToString(sum[:])}
}

func RandomState() string {
	raw := make([]byte, 16)
	mustRead(rand.Read(raw))
	return base64.RawURLEncoding.EncodeToString(raw)
}

func mustRead(_ int, err error) {
	if err != nil {
		panic(err)
	}
}
```

```go
func newLoginCmd() *cobra.Command {
	var issuer string
	cmd := &cobra.Command{
		Use:   "login",
		Short: "通过浏览器授权码 + PKCE 登录",

			token, err := runPkceFlow(cmd.Context(), issuerURL, cfg.ClientID)
			if err != nil {

			}

			return nil
		},

func runPkceFlow(ctx context.Context, issuer, clientID string) (auth.Tokens, error) {
	verifier := auth.NewCodeVerifier()
	state := auth.RandomState()
	redirect := fmt.Sprintf("http://127.0.0.1:%d/callback", loopbackPort)

	listener, err := net.Listen("tcp", fmt.Sprintf("127.0.0.1:%d", loopbackPort))
	if err != nil {
		return auth.Tokens{}, fmt.Errorf("监听回调端口失败: %w", err)
	}
	defer listener.Close()

	type result struct {
		code string
		err  error
	}
	done := make(chan result, 1)
	srv := &http.Server{
		ReadHeaderTimeout: 10 * time.Second,
		Handler: http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
			q := r.URL.Query()
			if q.Get("state") != state {
				http.Error(w, "state 不匹配", http.StatusBadRequest)
				done <- result{err: fmt.Errorf("state 不匹配")}
				return
			}
			fmt.Fprintln(w, "登录完成，可以关闭本窗口。")
			done <- result{code: q.Get("code")}
		}),
	}
	go srv.Serve(listener)
	defer srv.Shutdown(context.Background())

	oauthCfg := oauth2.Config{
		ClientID:    clientID,
		RedirectURL: redirect,
		Endpoint: oauth2.Endpoint{
			AuthURL:  strings.TrimRight(issuer, "/") + "/protocol/openid-connect/auth",
			TokenURL: strings.TrimRight(issuer, "/") + "/protocol/openid-connect/token",
		},
		Scopes: []string{"openid", "profile", "email"},
	}
	authURL := oauthCfg.AuthCodeURL(state, oauth2.AccessTypeOffline,
		// PKCE S256
	)
	authURL = appendQuery(authURL, map[string]string{
		"code_challenge":        verifier.Challenge,
		"code_challenge_method": "S256",
	})
	openBrowser(authURL)

	select {
	case r := <-done:
		if r.err != nil {
			return auth.Tokens{}, r.err
		}
		tok, err := oauthCfg.Exchange(ctx, r.code, oauth2.SetAuthURLParam("code_verifier", verifier.Verifier))
		if err != nil {
			return auth.Tokens{}, err
		}
		return auth.Tokens{
			AccessToken:  tok.AccessToken,
			RefreshToken: tok.RefreshToken,
			ExpiresAt:    time.Now().Add(tok.Expiry),
		}, nil
	case <-time.After(5 * time.Minute):
		return auth.Tokens{}, fmt.Errorf("登录超时")
	}
}

func appendQuery(base string, params map[string]string) string {
	sep := "?"
	if len(base) > 0 && contains(base, '?') {
		sep = "&"
	}
	keys := make([]string, 0, len(params))
	for k := range params {
		keys = append(keys, k)
	}
	sortStrings(keys)
	for _, k := range keys {
		base += sep + url.QueryEscape(k) + "=" + url.QueryEscape(params[k])
		sep = "&"
	}
	return base
}

func openBrowser(target string) {
	var cmd *exec.Cmd
	switch runtime.GOOS {
	case "windows":
		cmd = exec.Command("rundll32", "url.dll,FileProtocolHandler", target)
	case "darwin":
		cmd = exec.Command("open", target)
	default:
		cmd = exec.Command("xdg-open", target)
	}
	_ = cmd.Start()
}

func defaultServerFallback() string {
	c, _ := config.Load()
	return c.Server
}
```

```go
type Problem struct {
	Type        string      `json:"type"`
	Title       string      `json:"title"`
	Status      int         `json:"status"`
	Code        string      `json:"code"`
	Detail      string      `json:"detail"`

type FieldErr struct {
	Field   string `json:"field"`
	Code    string `json:"code"`
	Message string `json:"message"`
}

// ProblemError 让调用方按 Code 分支，而不是解析 Detail 文本。
type ProblemError struct {
	HTTPStatus int
	Problem    Problem
}

func (e *ProblemError) Error() string {
	return fmt.Sprintf("%s (%d): %s", e.Problem.Code, e.HTTPStatus, e.Problem.Detail)
}

// CodeOf 提取服务端错误码；非 problem 响应返回空串。
func CodeOf(err error) string {
	if pe, ok := err.(*ProblemError); ok {
		return pe.Problem.Code
	}
	return ""
}
```

```go
package apiclient

import (
	"context"
	"encoding/json"
	"fmt"
	"io"
	"net/http"
	"net/url"
	"strconv"
	"strings"
	"time"
)

type Client struct {
	base    string
	token   string
	http    *http.Client
}

func New(baseURL, token string, timeout time.Duration) *Client {
	if timeout == 0 {
		timeout = 30 * time.Second
	}
	return &Client{
		base:  strings.TrimRight(baseURL, "/"),
		token: token,
		http:  &http.Client{Timeout: timeout},
	}
}

func (c *Client) do(ctx context.Context, method, path string, query url.Values, body any, out any) error {
	target := c.base + path
	if len(query) > 0 {
		target += "?" + query.Encode()
	}
	var reader io.Reader
	if body != nil {
		buf, err := json.Marshal(body)
		if err != nil {
			return err
		}
		reader = strings.NewReader(string(buf))
	}
	req, err := http.NewRequestWithContext(ctx, method, target, reader)
	if err != nil {
		return err
	}
	req.Header.Set("Accept", "application/json")
	if c.token != "" {
		req.Header.Set("Authorization", "Bearer "+c.token)
	}
	if body != nil {
		req.Header.Set("Content-Type", "application/json")
	}

	resp, err := c.http.Do(req)
	if err != nil {
		return fmt.Errorf("请求 %s 失败: %w", target, err)
	}
	defer resp.Body.Close()

	if resp.StatusCode < 200 || resp.StatusCode >= 300 {
		return decodeProblem(resp)
	}
	if out == nil {
		_, _ = io.Copy(io.Discard, resp.Body)
		return nil
	}
	return json.NewDecoder(resp.Body).Decode(out)
}

func decodeProblem(resp *http.Response) error {
	raw, _ := io.ReadAll(resp.Body)
	var p Problem
	if err := json.Unmarshal(raw, &p); err != nil || p.Code == "" {
		return &ProblemError{HTTPStatus: resp.StatusCode,
			Problem: Problem{Code: "HTTP_" + strconv.Itoa(resp.StatusCode), Status: resp.StatusCode,
				Detail: string(raw)}}
	}
	return &ProblemError{HTTPStatus: resp.StatusCode, Problem: p}
}

func (c *Client) Me(ctx context.Context) (MeResponse, error) {
	var out MeResponse
	return out, c.do(ctx, http.MethodGet, "/me", nil, nil, &out)
}

func (c *Client) Search(ctx context.Context, q, visibility, tag string, limit int, cursor string) (SkillPage, error) {
	query := url.Values{}
	if q != "" {
		query.Set("q", q)
	}
	if visibility != "" {
		query.Set("visibility", visibility)
	}
	if tag != "" {
		query.Set("tag", tag)
	}
	if limit > 0 {
		query.Set("limit", strconv.Itoa(limit))
	}
	if cursor != "" {
		query.Set("cursor", cursor)
	}
	var out SkillPage
	return out, c.do(ctx, http.MethodGet, "/skills", query, nil, &out)
}

func (c *Client) Skill(ctx context.Context, id string) (Skill, error) {
	var out Skill
	return out, c.do(ctx, http.MethodGet, "/skills/"+url.PathEscape(id), nil, nil, &out)
}

func (c *Client) Versions(ctx context.Context, id string) (VersionPage, error) {
	var out VersionPage
	return out, c.do(ctx, http.MethodGet, "/skills/"+url.PathEscape(id)+"/versions", nil, nil, &out)
}

// DownloadArtifact 取版本制品字节。走 stream 而不是 presigned URL，
// 避免把带权限的地址写进本地文件。
func (c *Client) DownloadArtifact(ctx context.Context, artifactID string) ([]byte, error) {
	target := c.base + "/artifacts/" + url.PathEscape(artifactID) + "/download?disposition=stream"
	req, err := http.NewRequestWithContext(ctx, http.MethodGet, target, nil)
	if err != nil {
		return nil, err
	}
	req.Header.Set("Authorization", "Bearer "+c.token)
	resp, err := c.http.Do(req)
	if err != nil {
		return nil, err
	}
	defer resp.Body.Close()
	if resp.StatusCode != http.StatusOK {
		return nil, decodeProblem(resp)
	}
	return io.ReadAll(resp.Body)
}
```

```go
package skillscan

import (
	"fmt"
	"os"
	"path/filepath"
	"strings"
)

type Limits struct {
	MaxFileBytes  int64
	MaxTotalBytes int64
	MaxFiles      int
}

// DefaultLimits 对应详细设计 §3.1.2 的 max_file_size_mb / max_total_size_mb。
var DefaultLimits = Limits{MaxFileBytes: 20 << 20, MaxTotalBytes: 50 << 20, MaxFiles: 5000}

// ValidateDir 在安装前校验目录：必须有 SKILL.md，不得有逃出根目录的符号链接，
// 单文件/总量/文件数不得超限。不跟随指向目录外的符号链接（详细设计 §6.1）。
func ValidateDir(dir string, limits Limits) error {
	info, err := os.Stat(dir)
	if err != nil || !info.IsDir() {
		return fmt.Errorf("Skill 目录不存在: %s", dir)
	}
	if _, err := os.Stat(filepath.Join(dir, "SKILL.md")); err != nil {
		return fmt.Errorf("缺少 SKILL.md，不是合法的 Skill 目录: %s", dir)
	}

	root, err := filepath.EvalSymlinks(dir)
	if err != nil {
		return fmt.Errorf("解析目录失败: %w", err)
	}

	var files int
	var total int64
	walkErr := filepath.Walk(root, func(path string, fi os.FileInfo, err error) error {
		if err != nil {
			return err
		}
		if fi.Mode()&os.ModeSymlink != 0 {
			target, err := filepath.EvalSymlinks(path)
			if err != nil {
				return fmt.Errorf("符号链接无法解析: %s", path)
			}
			if !within(root, target) {
				return fmt.Errorf("符号链接指向目录外，拒绝: %s", target)
			}
			return nil
		}
		if fi.IsDir() {
			if isIgnored(fi.Name()) && path != root {
				return filepath.SkipDir
			}
			return nil
		}
		files++
		if files > limits.MaxFiles {
			return fmt.Errorf("文件数超过上限 %d", limits.MaxFiles)
		}
		if fi.Size() > limits.MaxFileBytes {
			return fmt.Errorf("文件 %s 超过单文件大小上限 %d 字节", path, limits.MaxFileBytes)
		}
		total += fi.Size()
		if total > limits.MaxTotalBytes {
			return fmt.Errorf("目录总大小超过上限 %d 字节", limits.MaxTotalBytes)
		}
		return nil
	})
	if walkErr != nil {
		return walkErr
	}
	return nil
}

func within(root, target string) bool {
	rel, err := filepath.Rel(root, target)
	if err != nil {
		return false
	}
	return rel != ".." && !strings.HasPrefix(rel, ".."+string(filepath.Separator))
}

func isIgnored(name string) bool {
	switch name {
	case ".git", "node_modules", "__pycache__", ".venv":
		return true
	}
	return false
}
```

```go
package skillscan

import (
	"fmt"
	"os"
	"path/filepath"
	"strings"
)

// Candidate 是仓库里一个可能的 Skill 目录。
type Candidate struct {
	Dir        string
	Name       string
	HasSkillMd bool
}

// Candidates 找出根目录下所有含 SKILL.md 的子目录（深度上限 4）。
func Candidates(root string) ([]Candidate, error) {
	var out []Candidate
	err := filepath.Walk(root, func(path string, fi os.FileInfo, err error) error {
		if err != nil {
			return err
		}
		if !fi.IsDir() {
			return nil
		}
		rel, _ := filepath.Rel(root, path)
		if depth := len(strings.Split(filepath.ToSlash(rel), "/")); depth > 4 {
			return filepath.SkipDir
		}
		if fi.Name() == ".git" || fi.Name() == "node_modules" {
			return filepath.SkipDir
		}
		if path == root {
			return nil
		}
		if _, err := os.Stat(filepath.Join(path, "SKILL.md")); err == nil {
			out = append(out, Candidate{Dir: path, Name: filepath.Base(path), HasSkillMd: true})
		}
		return nil
	})
	if err != nil {
		return nil, fmt.Errorf("扫描候选目录失败: %w", err)
	}
	return out, nil
}

// SkillName 优先取 SKILL.md frontmatter 的 name，回退到目录名。
func SkillName(dir string) string {
	data, err := os.ReadFile(filepath.Join(dir, "SKILL.md"))
	if err != nil {
		return filepath.Base(dir)
	}
	for _, line := range strings.Split(string(data), "\n") {
		line = strings.TrimSpace(line)
		if strings.HasPrefix(line, "name:") {
			return strings.TrimSpace(strings.TrimPrefix(line, "name:"))
		}
	}
	return filepath.Base(dir)
}
```

```go
package gitx

import (
	"context"
	"fmt"
	"net/url"
	"os/exec"
	"strings"
)

// NormalizeURL 规范化仓库地址，并拒绝危险协议与内嵌凭据（详细设计 §7.3）。
func NormalizeURL(raw string) (string, error) {
	raw = strings.TrimSpace(raw)
	if strings.HasPrefix(raw, "file://") {
		return "", fmt.Errorf("拒绝 file:// 协议")
	}
	if strings.HasPrefix(raw, "git@") {
		return raw, nil
	}
	u, err := url.Parse(raw)
	if err != nil {
		return "", fmt.Errorf("解析仓库地址失败: %w", err)
	}
	switch u.Scheme {
	case "https", "ssh", "":
	default:
		return "", fmt.Errorf("只允许 https/ssh，实际为 %s", u.Scheme)
	}
	if u.User != nil && u.User.String() != "" {
		return "", fmt.Errorf("仓库地址不得内嵌凭据，请用 --credential-ref")
	}
	u.Fragment = ""
	return u.String(), nil
}

// Clone 把仓库浅克隆到 dest，返回实际解析到的 commit。
func Clone(ctx context.Context, repo, ref, dest string) (string, error) {
	run := func(args ...string) (string, error) {
		cmd := exec.CommandContext(ctx, "git", args...)
		cmd.Env = append(cmd.Environ(), "GIT_TERMINAL_PROMPT=0")
		out, err := cmd.CombinedOutput()
		if err != nil {
			return "", fmt.Errorf("git %s 失败: %w\n%s", strings.Join(args, " "), err, out)
		}
		return strings.TrimSpace(string(out)), nil
	}
	run("init", "--quiet", dest)
	run("-C", dest, "remote", "add", "origin", repo)
	if ref != "" {
		if _, err := run("-C", dest, "fetch", "--depth", "1", "origin", ref); err != nil {
			return "", err
		}
		if _, err := run("-C", dest, "checkout", "--quiet", "FETCH_HEAD"); err != nil {
			return "", err
		}
	} else {
		if _, err := run("-C", dest, "fetch", "--depth", "1", "origin"); err != nil {
			return "", err
		}
		run("-C", dest, "checkout", "--quiet", "FETCH_HEAD")
	}
	return run("-C", dest, "rev-parse", "HEAD")
}

// LsRemote 只取远端 ref 指向的 commit，不下载内容（详细设计 §3.7 的检查更新路径）。
func LsRemote(ctx context.Context, repo, ref string) (string, error) {
	args := []string{"ls-remote"}
	if ref == "" {
		args = append(args, repo, "HEAD")
	} else {
		args = append(args, repo, ref, ref)
	}
	cmd := exec.CommandContext(ctx, "git", args...)
	cmd.Env = append(cmd.Environ(), "GIT_TERMINAL_PROMPT=0")
	out, err := cmd.CombinedOutput()
	if err != nil {
		return "", fmt.Errorf("git ls-remote 失败: %w\n%s", err, out)
	}
	for _, line := range strings.Split(strings.TrimSpace(string(out)), "\n") {
		fields := strings.Fields(line)
		if len(fields) == 2 {
			return fields[0], nil
		}
	}
	return "", fmt.Errorf("远端未找到 ref: %s", ref)
}
```

```go
package installer

import (
	"fmt"
	"io"
	"os"
	"path/filepath"
	"runtime"
)

// InstallAtomic 把 src 目录装到 target：先复制到同级临时目录，校验通过后
// 原子切换。失败时 target 保持原样（附录 A.4）。
func InstallAtomic(src, target string, expectSkillMd bool) error {
	if expectSkillMd {
		if _, err := os.Stat(filepath.Join(src, "SKILL.md")); err != nil {
			return fmt.Errorf("源目录缺少 SKILL.md")
		}
	}
	parent := filepath.Dir(target)
	if err := os.MkdirAll(parent, 0o755); err != nil {
		return err
	}
	staging, err := os.MkdirTemp(parent, ".skillmesh-staging-*")
	if err != nil {
		return err
	}
	defer os.RemoveAll(staging)

	stagedTarget := filepath.Join(staging, filepath.Base(target))
	if err := copyTree(src, stagedTarget); err != nil {
		return fmt.Errorf("复制到暂存目录失败: %w", err)
	}

	backup := ""
	if _, err := os.Stat(target); err == nil {
		backup = target + ".skillmesh-backup"
		os.RemoveAll(backup)
		if err := os.Rename(target, backup); err != nil {
			return fmt.Errorf("备份现有安装失败: %w", err)
		}
	}
	if err := os.Rename(stagedTarget, target); err != nil {
		if backup != "" {
			_ = os.Rename(backup, target) // 回滚，恢复旧版本
		}
		return fmt.Errorf("切换安装目录失败: %w", err)
	}
	if backup != "" {
		os.RemoveAll(backup)
	}
	return nil
}

func copyTree(src, dst string) error {
	return filepath.Walk(src, func(path string, fi os.FileInfo, err error) error {
		if err != nil {
			return err
		}
		rel, err := filepath.Rel(src, path)
		if err != nil {
			return err
		}
		out := filepath.Join(dst, rel)
		if fi.IsDir() {
			return os.MkdirAll(out, 0o755)
		}
		if !fi.Mode().IsRegular() {
			return nil // 跳过符号链接等非普通文件
		}
		return copyFile(path, out, fi.Mode())
	})
}

func copyFile(src, dst string, mode os.FileMode) error {
	in, err := os.Open(src)
	if err != nil {
		return err
	}
	defer in.Close()
	if err := os.MkdirAll(filepath.Dir(dst), 0o755); err != nil {
		return err
	}
	out, err := os.OpenFile(dst, os.O_CREATE|os.O_WRONLY|os.O_TRUNC, mode.Perm())
	if err != nil {
		return err
	}
	if _, err := io.Copy(out, in); err != nil {
		out.Close()
		return err
	}
	return out.Close()
}

// IsManaged 判断目录是否由 SkillMesh 安装（存在 .skillmesh-install 标记）。
func IsManaged(dir string) bool {
	_, err := os.Stat(filepath.Join(dir, ".skillmesh-install"))
	return err == nil
}

func MarkInstalled(dir, source string) error {
	payload := source + "\n"
	if runtime.GOOS == "windows" {
		payload = "\n"
	}
	return os.WriteFile(filepath.Join(dir, ".skillmesh-install"), []byte(payload), 0o644)
}

// RemoveUnmanaged 拒绝删除不受管理的目录，避免误删用户手写 Skill。
func RemoveUnmanaged(dir string) error {
	if _, err := os.Stat(dir); os.IsNotExist(err) {
		return nil
	}
	if !IsManaged(dir) {
		return fmt.Errorf("%s 不由 SkillMesh 管理，拒绝删除（用 --replace 可覆盖）", dir)
	}
	return os.RemoveAll(dir)
}
```

```go
package lockfile

import (
	"fmt"
	"os"
	"path/filepath"

	"gopkg.in/yaml.v3"
)

// FileName / ManifestName 对应详细设计 §3.10。
const (
	FileName     = "skillmesh.lock.yaml"
	ManifestName = "skillmesh.yaml"
)

type Lock struct {
	Version    int           `yaml:"version"`
	ResolvedAt string        `yaml:"resolved_at"`
	Skills     []LockedSkill `yaml:"skills"`
}

type LockedSkill struct {
	Name           string   `yaml:"name"`
	SourceID       string   `yaml:"source_id,omitempty"`
	Repository     string   `yaml:"repository"`
	Path           string   `yaml:"path"`
	RefType        string   `yaml:"ref_type"`
	Ref            string   `yaml:"ref"`
	ResolvedCommit string   `yaml:"resolved_commit"`
	Version        string   `yaml:"version"`
	SHA256         string   `yaml:"sha256"`
	Agents         []string `yaml:"agents"`
}

func Path(projectRoot string) string { return filepath.Join(projectRoot, FileName) }

func Load(projectRoot string) (Lock, error) {
	var lock Lock
	data, err := os.ReadFile(Path(projectRoot))
	if os.IsNotExist(err) {
		return Lock{Version: 1}, nil
	}
	if err != nil {
		return lock, err
	}
	if err := yaml.Unmarshal(data, &lock); err != nil {
		return lock, fmt.Errorf("解析 %s: %w", FileName, err)
	}
	return lock, nil
}

func (l Lock) Save(projectRoot string) error {
	l.Version = 1
	data, err := yaml.Marshal(l)
	if err != nil {
		return err
	}
	return os.WriteFile(Path(projectRoot), data, 0o644)
}

func (l Lock) Find(name string) (LockedSkill, bool) {
	for _, s := range l.Skills {
		if s.Name == name {
			return s, true
		}
	}
	return LockedSkill{}, false
}
```

```go
func pickVersion(versions apiclient.VersionPage, want string, locked bool, fromLock lockfile.LockedSkill) apiclient.SkillVersion {
	if want == "" && locked && fromLock.Version != "" {
		want = fromLock.Version
	}
	for _, v := range versions.Items {
		if v.Status != "published" {
			continue
		}
		if want == "" || v.Version == want {
			if locked && fromLock.SHA256 != "" && v.Artifact != nil &&
				v.Artifact.SHA256 != fromLock.SHA256 {
				continue // 锁文件摘要不符，按未命中处理
			}
			return v
		}
	}
	return apiclient.SkillVersion{}
}
```

```go
package installer

import (
	"archive/zip"
	"bytes"
	"fmt"
	"io"
	"os"
	"path/filepath"
	"strings"
)

// extractZip 解包到 destRoot 并返回含 SKILL.md 的顶层目录。
// 拒绝路径穿越条目（详细设计 §3.5 安装事务第 3 步）。
func extractZip(data []byte, destRoot string) (string, error) {
	zr, err := zip.NewReader(bytes.NewReader(data), int64(len(data)))
	if err != nil {
		return "", fmt.Errorf("制品不是合法 zip: %w", err)
	}
	for _, f := range zr.File {
		if strings.HasPrefix(f.Name, "/") || strings.Contains(f.Name, "..") {
			return "", fmt.Errorf("制品包含路径穿越条目: %s", f.Name)
		}
	}
	for _, f := range zr.File {
		out := filepath.Join(destRoot, filepath.FromSlash(f.Name))
		if !withinRoot(destRoot, out) {
			return "", fmt.Errorf("制品包含路径穿越条目: %s", f.Name)
		}
		if f.FileInfo().IsDir() {
			if err := os.MkdirAll(out, 0o755); err != nil {
				return "", err
			}
			continue
		}
		if err := os.MkdirAll(filepath.Dir(out), 0o755); err != nil {
			return "", err
		}
		rc, err := f.Open()
		if err != nil {
			return "", err
		}
		mode := f.Mode().Perm()
		if mode == 0 {
			mode = 0o644
		}
		w, err := os.OpenFile(out, os.O_CREATE|os.O_WRONLY|os.O_TRUNC, mode)
		if err != nil {
			rc.Close()
			return "", err
		}
		if _, err := io.Copy(w, rc); err != nil {
			rc.Close()
			w.Close()
			return "", err
		}
		rc.Close()
		if err := w.Close(); err != nil {
			return "", err
		}
	}
	return findSkillRoot(destRoot)
}

func withinRoot(root, target string) bool {
	rel, err := filepath.Rel(root, target)
	return err == nil && rel != ".." && !strings.HasPrefix(rel, ".."+string(filepath.Separator))
}

// findSkillRoot 兼容两种打包布局：顶层直接是 SKILL.md，或包一层目录名。
func findSkillRoot(root string) (string, error) {
	if _, err := os.Stat(filepath.Join(root, "SKILL.md")); err == nil {
		return root, nil
	}
	entries, err := os.ReadDir(root)
	if err != nil {
		return "", err
	}
	for _, e := range entries {
		if !e.IsDir() {
			continue
		}
		candidate := filepath.Join(root, e.Name())
		if _, err := os.Stat(filepath.Join(candidate, "SKILL.md")); err == nil {
			return candidate, nil
		}
	}
	return "", fmt.Errorf("制品中找不到 SKILL.md")
}
```

```go
func trimBytes(b []byte) []byte {
	start, end := 0, len(b)
	for start < end && (b[start] == '\n' || b[start] == '\r' || b[start] == ' ') {
		start++
	}
	for end > start && (b[end-1] == '\n' || b[end-1] == '\r' || b[end-1] == ' ') {
		end--
	}
	return b[start:end]
}
```

```go
// UpdateInfo 是一次检查更新结果。
type UpdateInfo struct {
	Name         string
	Repository   string
	Path         string
	LocalCommit  string
	RemoteCommit string
}

// checkUpdates 只调 git ls-remote，不下载内容（详细设计 §3.7）。
func checkUpdates(ctx context.Context, lock lockfile.Lock) ([]UpdateInfo, error) {
	var out []UpdateInfo
	for _, s := range lock.Skills {
		if s.Repository == "" {
			continue
		}
		remote, err := gitx.LsRemote(ctx, s.Repository, s.Ref)
		if err != nil {
			return nil, fmt.Errorf("检查 %s 失败: %w", s.Name, err)
		}
		if remote != s.ResolvedCommit {
			out = append(out, UpdateInfo{
				Name: s.Name, Repository: s.Repository, Path: s.Path,
				LocalCommit: s.ResolvedCommit, RemoteCommit: remote,
			})
		}
	}
	return out, nil
}

func newUpdateCmd() *cobra.Command {
	var checkOnly, all bool
	cmd := &cobra.Command{
		Use:   "update [skill-name]",
		Short: "检查或应用更新",
		RunE: func(cmd *cobra.Command, args []string) error {
			root := mustGetwd()
			lock, err := lockfile.Load(root)
			if err != nil {
				return err
			}
			if len(args) == 1 {
				filtered := lockfile.Lock{Version: lock.Version}
				if s, ok := lock.Find(args[0]); ok {
					filtered.Skills = []lockfile.LockedSkill{s}
				} else {
					return fmt.Errorf("锁文件中没有 %s", args[0])
				}
				lock = filtered
			}
			updates, err := checkUpdates(cmd.Context(), lock)
			if err != nil {
				return err
			}
			if len(updates) == 0 {
				fmt.Println("全部为最新")
				return nil
			}
			w := tabwriter.NewWriter(os.Stdout, 0, 0, 2, ' ', 0)
			fmt.Fprintln(w, "SKILL\t本地 commit\t远端 commit\t状态")
			for _, u := range updates {
				status := "可更新"
				fmt.Fprintf(w, "%s\t%s\t%s\t%s\n", u.Name, short(u.LocalCommit), short(u.RemoteCommit), status)
			}
			if err := w.Flush(); err != nil {
				return err
			}
			if checkOnly || !all && len(args) == 0 {
				return nil
			}
			for _, u := range updates {
				if err := applyUpdate(cmd.Context(), root, lock, u); err != nil {
					return err
				}
			}
			return nil
		},
	}
	cmd.Flags().BoolVar(&checkOnly, "check", false, "只检查不应用")
	cmd.Flags().BoolVar(&all, "all", false, "应用全部更新")
	return cmd
}

// applyUpdate 走「临时目录 → 校验 → 原子替换」，本地有改动时保留并提示。
func applyUpdate(ctx context.Context, root string, lock lockfile.Lock, u UpdateInfo) error {
	work, err := os.MkdirTemp("", "skillmesh-update-*")
	if err != nil {
		return err
	}
	defer os.RemoveAll(work)

	repo := filepath.Join(work, "repo")
	commit, err := gitx.Clone(ctx, u.Repository, u.RemoteCommit, repo)
	if err != nil {
		return err
	}
	skillDir := filepath.Join(repo, filepath.FromSlash(u.Path))
	if err := skillscan.ValidateDir(skillDir, skillscan.DefaultLimits); err != nil {
		return err
	}
	name := skillscan.SkillName(skillDir)
	for _, agentName := range lock.Skills[0].Agents {
		base, err := agentDirFor(agentName, root)
		if err != nil {
			return err
		}
		target := filepath.Join(base, name)
		if err := installer.InstallAtomic(skillDir, target, true); err != nil {
			return err
		}
		installer.MarkInstalled(target, u.Repository)
	}
	for i := range lock.Skills {
		if lock.Skills[i].Name == u.Name {
			lock.Skills[i].ResolvedCommit = commit
		}
	}
	if err := lock.Save(root); err != nil {
		return err
	}
	fmt.Printf("已更新 %s 到 %s\n", u.Name, short(commit))
	return nil
}

func short(sha string) string {
	if len(sha) > 8 {
		return sha[:8]
	}
	return sha
}
```

```ts
import type { Skill, SkillPage, SkillVersion } from './types'

const BASE = '/api/v1'

export class ApiError extends Error {
  constructor(readonly code: string, readonly status: number, message: string) {
    super(message)
  }
}

async function request<T>(path: string, token: string): Promise<T> {
  const res = await fetch(BASE + path, {
    headers: token ? { Authorization: `Bearer ${token}` } : {},
  })
  if (!res.ok) {
    let code = `HTTP_${res.status}`
    let message = res.statusText
    try {
      const body = await res.json()
      code = body.code ?? code
      message = body.detail ?? message
    } catch {
      /* 非 JSON 错误体，沿用状态码 */
    }
    throw new ApiError(code, res.status, message)
  }
  return (await res.json()) as T
}

export function searchSkills(q: string, token: string): Promise<SkillPage> {
  const params = new URLSearchParams()
  if (q) params.set('q', q)
  return request<SkillPage>(`/skills?${params}`, token)
}

export function getSkill(id: string, token: string): Promise<Skill> {
  return request<Skill>(`/skills/${id}`, token)
}

export function getVersions(id: string, token: string): Promise<{ items: SkillVersion[] }> {
  return request<{ items: SkillVersion[] }>(`/skills/${id}/versions`, token)
}
```
